## B안 — Blue Playground

기존 A안은 `/`, B안은 **http://localhost:3000/b/** 에서 확인합니다. 같은 `python3 server.py` 명령으로 실행합니다.

- 원페이지: 히어로 → Studio → 캐릭터 자판기 → 클라이언트 띠배너 → Contact.
- 고정 GNB의 앵커 이동, 현재 섹션 표시, 모바일 메뉴, 직접 해시 접속 지원.
- 스크롤 진행도에 연결된 캐릭터 정면→후면 회전과 오른쪽 이동, 소개 전환 및 역재생.
- 자판기 상품은 걸이 탭·번호 라벨·투명 블리스터 케이스를 갖춘 6개 패키지로 표시합니다. 오키몽 단독 이미지는 기존 턴어라운드를 참고한 생성 에셋이며 원본 포스터는 상세 모달에서 확인할 수 있습니다.
- 자판기 버튼으로 작업 상세 모달 열기. 닫기·Escape·뒤로 가기와 선택 위치 복원.
- Contact는 아래에서 위로 차오르는 첫 진입 효과와 인라인 문의 양식(회사명·담당자명·연락처·이메일·요청사항)을 제공합니다. 문의 팝업은 제거했으며 작업 상세 모달은 유지합니다.
- 문의는 기존 `/api/contact`를 사용합니다. SMTP 미설정 시 실제 발송은 되지 않으며 오류 안내와 입력 보존이 동작합니다.
- 모션 감소 및 높이 700px 이하 화면에서는 읽기 쉬운 정적 구성으로 전환합니다.

구현 파일: `public/b/index.html`, `public/b/style.css`, `public/b/app.js`.

회전 에셋 `public/b/assets/okk-rotation.png`는 원본 턴어라운드를 참고해 생성한 **15프레임 검토용 시퀀스**입니다. 원본 모델의 정확한 각도 렌더가 아니므로 외형과 회전 간격을 검수한 후 최종 렌더 시퀀스로 교체할 수 있습니다. 원본 이미지는 변경하지 않았습니다. 자판기는 제공된 포스터와 턴어라운드를 활용한 6개 쇼케이스(데스크톱 3열 2행, 모바일 2열 3행)를 사용하며, 실제 프로젝트 실적을 임의로 추가하지 않았습니다. 소개 문구는 초안입니다.

## 구성

- `/`: 진입 원 확대 → 마스코트 자리 확대 및 인사 모션 → 히어로 → 글자별 낙하, 작업, 클라이언트, 문의
- `/about`: 스튜디오 소개 초안 및 이미지 자리
- `/works`, `/works/project-01`~`04`: 작업 목록 및 상세 이미지 자리
- Contacts: 공통 모달, 키보드 포커스, 필수 입력 검사, 전송 상태 및 오류 표시
- 모바일 대응, 모션 감소 설정 지원, 스크롤로 진입 연출 생략

`public/app.js`의 works 배열에서 작업 데이터를 관리합니다. `placeholder()`가 이미지 자리를, `setupHero()`가 마스코트 반응을 담당합니다. `public/style.css`에서 디자인과 진입 타이밍을 수정합니다. 사용된 15개 클라이언트 기본 로고는 `public/assets`에 복사했습니다.

## 준비할 자료

히어로에는 제공된 오키키 포스터 원본을 사용하며, 클릭 시 이미지 전체가 가볍게 움직입니다. 스튜디오 소개에는 오키키·오키몽의 설명, 포스터와 턴어라운드를 반영했습니다. 실제 손 흔들기와 표정 연기는 단독 이미지 및 진입·대기·클릭·스크롤 영상 수령 후 연결해야 합니다. 작업 이미지/실적, 소개 문구, 로고 원본 및 Pretendard 폰트 파일도 준비가 필요합니다. 현재 폰트는 설치된 Pretendard 또는 시스템 폰트로 표시합니다.

## 문의 발송 설정

서버 실행 환경에 `SMTP_HOST`, `SMTP_PORT`(기본 465), `SMTP_FROM`(인증된 발신 주소), `SMTP_USER`, `SMTP_PASSWORD`를 설정합니다. 465는 TLS, 다른 포트는 STARTTLS를 사용합니다. 비밀번호는 public 폴더에 저장하지 않습니다. 수신자는 서버에서 `ouog22@gmail.com`으로 고정되어 있습니다.

설정 전 접수 시 준비 중 메시지를 표시하며 입력을 보존합니다. 실제 발송 성공을 가짜로 표시하지 않습니다. SMTP 서버가 메시지를 접수해야 성공을 반환합니다. 실제 수신함 도착은 운영 설정 후 확인해야 합니다. 문의 데이터는 별도 저장하지 않습니다. 현재 개인정보 안내는 초안이며 보관 기간 등 운영 정책을 확정한 후 공개합니다.

이 서버는 로컬 검토용입니다. 공개 배포 시 운영 서버, HTTPS, SMTP 인증 및 개인정보 안내를 구성해주세요.
